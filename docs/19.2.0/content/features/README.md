# Features

| Feature | What it gives you |
|---------|-------------------|
| [Code Editor](code-editor.md) | One CodeMirror `EditorView` configured through inputs. |
| [Diff Editor](diff-editor.md) | A side-by-side `MergeView` of an original and a modified document. |
| [Languages](languages.md) | Syntax highlighting loaded on demand from a `LanguageDescription` list. |
| [Themes](themes.md) | The default light look or any CodeMirror theme `Extension`. |
| [Extensions](extensions.md) | `basic` / `minimal` setups plus your own CodeMirror extensions. |
| [Forms Integration](forms-integration.md) | `ngModel` and reactive forms through `ControlValueAccessor`. |
