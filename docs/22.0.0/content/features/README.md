# Features

| Feature | Summary |
|---------|---------|
| [Code Editor](code-editor.md) | A single CodeMirror editor, `ngx-code-editor`. |
| [Diff Editor](diff-editor.md) | Side-by-side comparison, `ngx-code-diff-editor`. |
| [Unified Diff Editor](unified-diff-editor.md) | One editor with inline accept/reject, `ngx-code-unified-diff-editor`. |
| [Forms Integration](forms-integration.md) | Signal Forms, reactive forms, `ngModel` and `[(value)]`. |
| [Themes](themes.md) | Built-in, registered, lazy and `'auto'` themes. |
| [Extensions](extensions.md) | Global, per-editor, lazy and preset extensions. |
| [Convenience Inputs](convenience-inputs.md) | Line numbers, search, autocompletion, lint and more without extension code. |
| [Error Handling](error-handling.md) | Typed `error` output instead of thrown exceptions. |
| [SSR and Zoneless](ssr-and-zoneless.md) | How views are created and what runs on the server. |
