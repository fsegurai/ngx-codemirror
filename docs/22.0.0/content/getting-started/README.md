# Getting Started

Three steps take you from zero to a configured editor.

1. [Installation](installation.md) - add the library and its peer dependencies.
2. [Quick Start](quick-start.md) - import a component and bind its value.
3. [Configuration](configuration.md) - set defaults, themes and extensions with `provideCodeEditor()`.
